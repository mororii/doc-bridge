DOCBRIDGE 초보자 설치 안내
==========================

중요: ZIP 안에서 바로 실행하지 말고 먼저 "모두 압축 풀기"를 하세요.

1. Codex, Claude, Kimi, Cursor, Excel, 한글, AutoCAD를 모두 종료합니다.
2. 선택 사항: 0-VERIFY.cmd를 더블클릭해 PASS를 확인합니다.
3. 1-INSTALL.cmd를 더블클릭하고 완료될 때까지 기다립니다.
4. 반드시 INSTALLATION SUCCESS가 나온 것을 확인한 뒤 아무 키나 누릅니다.
5. Codex/Claude/Kimi/Cursor를 다시 실행하고 새 대화를 시작합니다.
6. 2-TEST.cmd를 실행해 모든 핵심 항목이 [OK]인지 확인합니다.
   Codex가 설치된 PC는 아래 두 항목이 반드시 [OK]여야 합니다.
   - Codex CLI discovery
   - Codex plugin CLI mode
   - Codex marketplace registered (현재 CLI)
   - Codex plugin installed and enabled (구형 CLI에서만 표시)
   - Codex MCP visible and enabled
7. Excel 통합문서를 하나 연 뒤 2-EXCEL-LIVE-TEST.cmd를 실행해 PASS를 확인합니다.
   기본 2-TEST.cmd는 Excel을 새로 실행하지 않으므로 RCW 실동작은 이 단계에서 확인합니다.

주의:
  2-TEST.cmd는 설치 파일이 아닙니다. 1-INSTALL.cmd보다 먼저 실행하지 마세요.
  TEST NOT STARTED가 나오면 ZIP을 모두 압축 해제한 뒤 1-INSTALL.cmd부터 실행하세요.
  Codex/Kimi 등이 설치되지 않은 PC의 [SKIP] 표시는 오류가 아닙니다.
  Cursor는 사용자 전역 %USERPROFILE%\.cursor\mcp.json만 자동 병합합니다.
  프로젝트별 .cursor\mcp.json은 변경하지 않습니다.
  Cursor global config가 [OK]인지 확인하고 Cursor를 완전히 재시작하세요.
  Codex 재실행 뒤에는 기존 작업이 아니라 새 작업을 만드세요.
  새 작업에 DocBridge 도구가 없으면 프로젝트 파일을 수정하게 두지 말고 2-TEST.cmd를 다시 확인하세요.

첫 요청 예시:
  DocBridge 연결 상태를 확인하고 core_ping 결과를 보여줘. 아직 문서는 수정하지 마.

설치 위치:
  %LOCALAPPDATA%\DocBridge

진단 결과:
  %LOCALAPPDATA%\DocBridge\doctor-report.json

백업 위치:
  %LOCALAPPDATA%\DocBridge\backups

제거:
  3-UNINSTALL.cmd를 더블클릭하고 Y를 누릅니다.

화면과 문제 해결 방법은 사용설명서_보고따라하세요.html을 더블클릭해 확인하세요.
