# DocBridge 0.4.24 릴리스 노트

기준일: 2026-09-17. 이전 공개 릴리스 v0.4.23 이후의 한글(HWP) 실무 기능과 연결 안정화 작업을 묶었다.

## 새로 추가된 HWP 쓰기 op 2종

- `table_delete` — 표 전체를 삭제한다. `{tableIndex}`만 받으며 컨트롤 직접 선택
  방식이라 병합 표도 삭제된다. 표 개수 -1로 검증한다. 구조 파괴적이므로 high-risk
  (`highRiskConfirm` 필요). 행·열 최소 1개 유지 강제 때문에 전체 삭제가 안 되던
  제약을 해소한다.
- `table_set_borders` — 표 바깥 테두리 굵기를 지정한다. `{tableIndex, widthMm(0.1~5),
  color?(#RRGGBB), edges?(top|right|bottom|left, 기본 전체)}`. 내부는 건드리지
  않으며 네 변과 내부 한 셀을 재조회로 대조 검증한다. 직사각형이 아닌 표(병합 등)는
  변경 없이 실패한다. 굵기는 HWP 단계값(`HwpLineWidth`, 예: 0.5mm→7, 1.0mm→10)으로
  매핑되며 같은 문자열 왕복이 일치해야 통과한다. `"1mm"` 형식은 E_FAIL이므로
  `"1.0mm"`처럼 소수점을 붙인다.

## 연결 끊김 수정 (소유 인스턴스 핀)

- 홀더가 끝난 자동화 HWP는 창을 숨기므로 기존 가시성 탐색에서 빠져 고아가 됐다.
  ROT 등록 자체는 유지됨을 실측으로 확인했다.
- `hwp_launch`가 소유 인스턴스를 만들 때 `%LOCALAPPDATA%\DocBridge\hwp-instance-pin.json`에
  PID를 기록한다. 표시 창이 하나도 없으면 핀 PID로 직접 재연결하고 창을 다시 표시한다.
  핀 주인이 아니므로 소유하지 않고(종료·삭제 안 함), PID·이미지명·시작시각으로 검증한다.
- 가시성 판단도 문서창 루트 대신 프로세스 주 창 기준으로 바꿨다.

## 테스트 근거 (로컬, 한글 2024 13.0.0.866)

- 통합 Release `-warnaserror` 경고 0·오류 0.
- COM-free Core 1012·MCP 20.
- 소유 탭 E2E: 기존 3종 + 표 삭제(병합+각주 고아 포함) + 외곽선(0.5/1.0/부분변) + 핀 복구.
  HWP 전체 150/150.
- 실전 검증: 안전관리조직도 박스형 재구축, 추석연휴 비상연락망 실문서 수정·원복,
  표 외곽선 1.0→0.5→우하단만 변경. 전부 readback verified.
- E2E 하네스 정리: 테스트 종료 시 소유 프로세스를 완전 종료해 창이 쌓이지 않는다.
  (ExclusiveNewProcess 증명된 경우만, 저장 안 함.)

## 이전 버전 대비

- 0.4.23의 각주/미주/표제행/글자 효과/개요 수준/줄번호 그대로 포함.
- `table_delete`는 high-risk, `table_set_borders`는 일반 쓰기(자동실행 제외).
