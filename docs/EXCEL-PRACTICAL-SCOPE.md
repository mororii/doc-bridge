# Excel 실무 기능 범위와 작업 산정

2026-09-12 사용자 지시: 기존 기능을 파악해 활용하고, 글자·셀·그래프·표·도형 등의 생성·삭제·편집을 포함한다. 이후 모든 작업은 hermesscop의 범위·작업량·시간 산정 절차를 따른다.

| 업무 대상 | 필요한 작업 |

## 2026-09-17 지정 창 고정 (instance pin)

여러 Excel이 열려 있을 때 자동 선택이 엇갈린다는 현장 지적을 반영했다.
`excel_launch`에 `processId`/`hwnd` 쌍·단독 또는 `activeWindow:true`로 창을
지정하면 핀 파일(`%LOCALAPPDATA%\DocBridge\excel-instance-pin.json`)에 저장되고,
이후 모든 호출이 그 창에만 붙는다. 핀 창 소멸 시 다른 창을 몰래 쓰지 않고
`[EXCEL_PINNED_INSTANCE_GONE]`으로 중단한다. Excel이 최상위 창 핸들을
재생성하면 프로세스 시작 시각으로 동일 프로세스를 확인해 핀을 자가치유한다.
워커 경로(`--excel-worker`)에도 `launch`를 연결해 CLI/MCP 모두 동작한다.
참고: inline-ai의 포그라운드·HWND 집합 추적 원칙을 차용하되, 창 이동·스냅은
포그라운드 보존 철학과 반대라 제외했다. `dedicatedInstance`와 지정자는
排他, 핀 없이는 종전 동작 그대로다.
